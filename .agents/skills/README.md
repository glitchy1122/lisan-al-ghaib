# Portable agent skills

These skills live in the repo so **any** AI/IDE can follow the same procedures.

| Skill | Use when |
|-------|----------|
| `session-handoff` | Parking or resuming work across tools |
| `seed-handoff-from-chat` | Fill handoff from current AI conversation |
| `update-context` | Durable product/process facts changed |
| `write-adr` | Making a lasting architecture choice |
| `git-workflow` | Committing, branching, pushing for handoff |

Cursor may also load skills from the editor; keep **project** procedures here so Claude Code / Copilot / Codex see them too.
