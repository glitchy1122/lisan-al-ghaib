# Workflow: session start / end

## Start

1. Read `docs/handoff/CURRENT.md`
2. Skim `CONTEXT.md`
3. `git status` && `git log --oneline -10`
4. Continue from **Next**

## End

1. Update handoff status / done / next / blockers
2. ADR if a lasting decision was made
3. Update `CONTEXT.md` if product facts changed
4. Commit + push
